# Responsive UI & Cross-Device Optimization Changelog

**Project**: Sri Vengamamba Tours & Travels  
**Target Viewports**: 320px – 2560px  
**Date**: September 28, 2026  

---

| File | Component | Problem | Fix | Viewport Affected | Validation Result |
|---|---|---|---|---|---|
| `public/contact.html` | `.contact-page-layout` | Hardcoded inline style `grid-template-columns: 1fr 1fr` forced 2 narrow columns on small screens, breaking form and map layout. | Replaced inline styles with semantic `.contact-page-layout` class mapped to responsive CSS Grid rules. | Mobile & Tablet (≤960px) | **PASS** — Form and contact details stack cleanly into 1 column with comfortable spacing. |
| `public/about.html` | `.pillar-cards-grid` | Hardcoded inline style `repeat(auto-fit, minmax(280px, 1fr))` caused horizontal card overflow on 320px screens. | Replaced with semantic `.pillar-cards-grid` and `.pillar-card` using `repeat(auto-fit, minmax(min(100%, 260px), 1fr))`. | Small Mobile (≤360px) | **PASS** — Pillars fit seamlessly without horizontal scroll down to 320px. |
| `public/css/cinema.css` | `.header`, `.nav-contact`, `.brand-logo` | Header content (logo + CTA button + hamburger toggle) collided or overflowed on narrow phones (320px–360px). | Added `@media (max-width: 480px)` and `@media (max-width: 360px)` fluid padding, scaled logo height (30px/26px), compact CTA padding, and hid CTA arrow on ≤360px. | Small & Modern Mobile (320px–480px) | **PASS** — Header maintains elegant margins, zero collision, and pristine branding. |
| `public/css/cinema.css` | `nav.open` (Drawer) | Mobile nav drawer on short phone screens could clip bottom navigation links. | Added `max-height: calc(100svh - 85px); overflow-y: auto; overscroll-behavior: contain;` for smooth drawer scrolling. | Mobile & Tablet (≤960px) | **PASS** — All navigation links fully accessible even on small landscape phone viewports. |
| `public/css/cinema.css` | `.form-grid`, `.contact-form-card` | 2-column input fields were cramped on mobile (<640px), and 14.5px font triggered iOS Safari auto-zoom. | Added `@media (max-width: 640px)` for 1-column stack and set `font-size: 16px` on inputs/selects/textareas to stop auto-zoom. | Mobile (≤640px) | **PASS** — Inputs fit viewport width with zero zoom disruption on focus. |
| `public/css/cinema.css` | `.card-actions` (`.btn-whatsapp`, `.btn-call`) | Side-by-side WhatsApp and Call buttons wrapped awkwardly or caused text clipping on small phones. | Added `@media (max-width: 420px)` stacking actions vertically (`width: 100%; min-height: 44px; justify-content: center;`). | Small Mobile (≤420px) | **PASS** — Comfortable touch targets meeting WCAG 2.1 touch criteria. |
| `public/css/cinema.css` | `.services-filter` | 4 category filter tabs wrapped into multiple uneven lines, cluttering the screen on mobile devices. | Added `@media (max-width: 768px)` horizontal scroll container (`overflow-x: auto; flex-wrap: nowrap; scrollbar-width: none;`) for app-like swipe navigation. | Mobile & Tablet (≤768px) | **PASS** — Fluid horizontal swipe, zero page overflow, tabs easy to tap. |
| `public/css/cinema.css` | `.review-card`, `.marquee-track` | Fixed 310px–380px review card width caused horizontal overflow when tested at 320px viewport width. | Added fluid clamp: `flex: 0 0 calc(100vw - 48px) !important; max-width: 340px !important; min-width: 260px !important;` at ≤480px. | Mobile (320px–480px) | **PASS** — Continuous marquee loops smoothly with card width dynamically adapted to viewport. |
| `public/css/cinema.css` | `.page-hero`, `.page-hero-stats` | Subpage hero padding and stat pills wrapped awkwardly on narrow screens. | Added `@media (max-width: 640px)` reducing hero top padding to 105px and stacking stat pills vertically. | Mobile (≤640px) | **PASS** — Clean visual hierarchy, zero overlap with fixed header. |
| `public/css/cinema.css` | `.site-footer`, `.social-rail` | Floating social rail and footer text risked clashing with iOS navigation bar/home indicator. | Added `env(safe-area-inset-bottom)` support to footer bottom padding and social rail offset. | Modern Mobile (iPhone X and newer) | **PASS** — Safe margin maintained above iOS home indicator. |
| `public/css/cinema.css` | `.lb-nav`, `.lb-close` | Lightbox navigation buttons were too close to the screen edges on small devices. | Added `@media (max-width: 480px)` adjusting button dimensions (38px) and positioning (6px from edges). | Mobile (≤480px) | **PASS** — Lightbox navigation easy to operate without obscuring the active photo. |
| `public/js/main.js` | Mobile Menu Toggle | Menu did not automatically close when the user clicked outside the header. | Added document click listener: `document.addEventListener('click', e => { if (nav && nav.classList.contains('open') && header && !header.contains(e.target)) closeMenu(); });`. | Mobile & Tablet (≤960px) | **PASS** — Smooth outside-click dismissal matching native mobile UX expectations. |
| `public/css/cinema.css` | Global Containers | Accidental sideways scroll prevention across all devices. | Enforced `html, body { max-width: 100vw; overflow-x: hidden; position: relative; }` and `img, svg, video { max-width: 100%; height: auto; }`. | All Viewports (320px–2560px) | **PASS** — Zero horizontal scrollbar on any page or screen size. |
| `public/about.html`, `public/contact.html`, `public/services.html`, `public/gallery.html` | `.about-reviews-header` | 4.6★ verified review badge was accidentally duplicated twice side-by-side above review marquees. | Removed the duplicate inner score and badge metadata from the left heading block; restored clear section title paired with a single interactive review badge. | All Viewports (Mobile & Desktop) | **PASS** — Single, clean review badge displayed with zero repetition. |
| `public/contact.html`, `public/css/cinema.css` | `.map-embed`, `.btn-map-directions` | Map embed on mobile was restricted to 220px/260px, making street-level zooming and landmark navigation cramped. | Increased mobile map height to 350px/360px with `z=16` zoom level; added prominent `.btn-map-directions` CTA for 1-tap Google Maps directions. | Mobile (≤720px) | **PASS** — Street-level map is tall, clear, zoomable, and easy to navigate on phones. |
| `public/contact.html`, `public/css/cinema.css` | `.contact-form-card`, `.dispatch-desk-card`, `.location-map-card` | Desktop 36px card padding constricted form inputs and map on narrow phone screens. | Converted inline styles to responsive card classes with `padding: clamp(18px, 4.5vw, 24px)` on mobile, giving inputs 36px more horizontal width. | Mobile (≤640px) | **PASS** — Form fields and submit button feel open, legible, and comfortable to tap. |
| `public/gallery.html`, `public/js/cinema.js`, `public/css/cinema.css` | `.film-frame`, `#fleet-film` ("THE TRAVELLER / ON FILM") | Video was missing native `<source>` element and proper autoplay/muted/playsinline attributes; `.film-frame` had legacy hardcoded `height: 480px` leaving a massive empty black box on mobile. | Added native `<source src="assets/video/traveller-night.mp4">` with `autoplay muted loop playsinline controls preload="auto"`; updated `.film-frame` to responsive `aspect-ratio: 16 / 9 !important; height: auto !important;`; closed missing `</div>` on `.film-layout`; added IntersectionObserver autoplay on view in `cinema.js`. | All Viewports (Mobile to Desktop) | **PASS** — Video autoplays seamlessly, perfectly fitted to 16:9 frame with zero black empty space on mobile. |
| `public/css/cinema.css`, `public/index.html`, `public/about.html` | `.about-story-actions`, `.about-trust-card`, `.about-call-link` | "READ OUR FULL STORY" button, helpline telephone number, and 4.6 rating card were crowded with minimal vertical spacing on mobile screens. | Configured `.about` as responsive 2-column grid on desktop and 1-column on mobile (`gap: 48px`); set `.about-story-actions` to `flex-direction: column; gap: 16px; margin-bottom: 12px;` on mobile; added `margin-top: 16px` to `.about-trust-card`. | Mobile & Tablet (≤960px) | **PASS** — Clean, balanced spacing (16px vertical gap between button & helpline, and 50px+ breathing room above the rating card). |
